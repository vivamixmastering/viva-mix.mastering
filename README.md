# 🎚️ MixMaster Bot — ربات تلگرامی میکس و مستر

ربات تلگرامی که آهنگ/وکال می‌گیره و با **۱۰ پریست حرفه‌ای** (بر اساس زنجیره مهندس‌های معروف دنیا)
میکس و مسترش می‌کنه و فایل نهایی رو برمی‌گردونه. کاملاً ابری — روی **Render** اجرا می‌شه و
کلید **روشن/خاموش** هم روی خود ربات داره.

---

## ✨ چی کار می‌کنه؟

**۴ حالت پردازش:**

| حالت | ورودی | خروجی |
|---|---|---|
| 🎤 وکال خالی | فقط صدای خودت | وکال پردازش‌شده با زنجیره کامل |
| 🎵 آهنگ کامل | آهنگ بدون میکس/مستر | آهنگ مسترشده (۱۰ پریست) |
| 🎛️ وکال + بیت | دو فایل: وکال و موزیک | میکس و مستر نهایی |
| ✨ هوشمند | فقط آهنگ کامل | ربات خودش وکال رو با **Demucs (هوش مصنوعی)** جدا می‌کنه، وکال و موزیک رو **جداگونه** پردازش می‌کنه و دوباره میکس و مستر می‌کنه |

**زنجیره وکال (شبیه استودیوهای حرفه‌ای):**
HPF → گیت نرم (حذف هیس سکوت‌ها) → اصلاح نت نرم (اتوتیون متن‌باز — صدای رباتی نمی‌کنه)
→ کمپرسور سبک ۱۱۷۶ → کمپرسور نرم LA-2A → **کمپرسور موازی NY (حجم و چگالی)**
→ EQ (گرمی بم، پاکسازی میدرنج، حضور، درخشش) → دی‌اسر → گرم‌ساز (اشباع لامپی)
→ **هوا و جزئیات ریز تیس (Air Exciter ضد الیاسینگ)** → اکو → ریورب → نرمال‌سازی LUFS

**زنجیره مستر:**
HPF → EQ اصلاحی → کمپرسور باس (چسبندگی) → EQ تُنال → پهنای استریو Mid/Side → اشباع → لیمیتر
→ بلندی نهایی LUFS با سقف True Peak

**۱۰ پریست:** 📻 پاپ رادیویی • 🔥 کلابی پرانرژی • 🌙 آراندبی گرم • 🎸 آکوستیک طبیعی •
💧 بالاد احساسی • 🌟 پاپ ایرانی • 📼 وینتج تیپ • 🎧 لوفای ایندی • 📡 پخش رادیو و تلویزیون (EBU R128) •
🎬 سینمایی واید

## 🔌 کلید روشن/خاموش روی خود ربات

- `/on` → متغیر `BOT_POWER` رو از طریق **API رندر** روی `on` می‌ذاره و سرویس رو دوباره راه می‌ندازه
- `/off` → ربات می‌ره به حالت خواب (هیچ پردازشی انجام نمی‌شه، فقط `/on` جواب می‌ده)

چرا کامل suspend نمی‌شه؟ چون اگه سرویس کلاً خاموش بشه، دیگه `/on` رو هم نمی‌شنوه! 😄
برای خاموشی کامل، از داشبورد رندر «Suspend» بزن.

> اگه `RENDER_API_KEY` تنظیم نشه، کلید فقط توی حافظه عمل می‌کنه (که با خواب خودکار رندر
> روی پلن رایگان عملاً همون کار رو می‌کنه).

## 🚀 راه‌اندازی کامل (کد → گیت‌هاب → رندر)

### ۱) توکن ربات
1. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده → `/newbot` → اسم و یوزرنیم بده
2. توکن دریافتی (شکل `123456:ABC...`) رو کپی کن

### ۲) آپلود روی گیت‌هاب
```bash
cd mixmaster-bot
git init
git add .
git commit -m "MixMaster Bot"
git branch -M main
git remote add origin https://github.com/USERNAME/mixmaster-bot.git
git push -u origin main
```

### ۳) دیپلوی روی رندر (رایگان)
1. برو به [render.com](https://render.com) → ثبت‌نام با گیت‌هاب → **New +** → **Blueprint**
2. ریپوی `mixmaster-bot` رو انتخاب کن — فایل `render.yaml` خودش همه‌چیز رو می‌سازه
3. بعد از ساخت سرویس، توی **Environment** این متغیرها رو تنظیم کن:

| متغیر | مقدار |
|---|---|
| `BOT_TOKEN` | توکن BotFather |
| `ADMIN_ID` | آیدی عددی خودت از [@userinfobot](https://t.me/userinfobot) (فقط تو بتونی `/on` و `/off` بزنی) |
| `BOT_POWER` | `on` (پیش‌فرض) |
| `SMART_MODE` | برای حالت جداسازی هوشمند `1` بذار؛ اگه نمی‌خوای `0` |
| `RENDER_API_KEY` | (اختیاری) برای کلید واقعی روشن/خاموش — از داشبورد رندر: **Account Settings → API Keys** |
| `RENDER_SERVICE_ID` | (اختیاری) شناسه سرویس — توی آدرس داشبورد سرویس `https://dashboard.render.com/web/srv-XXXX` |

4. دکمه **Deploy** — تمام! ربات آنلاینه 🎉

### 🧠 حافظه رم — کدوم سرور برای کدوم حالت؟

پردازش صدا رم می‌خواد. کل کد برای **مصرف رم مستقل از طول آهنگ** بهینه شده:
همه مراحل سنگین (اصلاح نت، اشباع، هوا، دی‌اسر، جداسازی) به‌صورت بلوکی با اتصال نرم
پردازش می‌شن و همه محاسبات float32 خالصه (بدون کپی‌های float64). اعداد واقعیِ اندازه‌گیری‌شده:

| حالت | اوج رم (اندازه‌گیری شده) | رندر رایگان (512MB) | Hetzner 2GB (~۴€/ماه) |
|---|---|---|---|
| 🎤 وکال / 🎵 مستر / 🎛️ دو فایل | ~۵۰۰MB برای آهنگ ۹۰ ثانیه | ✅ جواب می‌ده (تا ~۳ دقیقه) | ✅ راحت |
| ✨ هوشمند (Demucs) | ~۱.۲GB | ❌ OOM می‌شه | ✅ (DEMUCS_CHUNK=5) |

**متغیرهای تنظیم رم:**

| متغیر محیطی | پیش‌فرض | توضیح |
|---|---|---|
| `DEMUCS_CHUNK` | `3` | طول هر قطعه جداسازی (ثانیه) — سرور ۲ گیگ: ۵، ۴+ گیگ: ۱۵ |
| `DEMUCS_THREADS` | `1` | تعداد هسته‌های CPU برای جداسازی |
| `AUTOTUNE_CHUNK` | `45` | طول هر قطعه اصلاح نت (ثانیه) |

**اگه رم کم بیاد چی می‌شه؟** همون درخواست خطا می‌گیره و پروسه توسط سیستم کشته می‌شه،
ولی رندر خودش ربات رو در چند ثانیه دوباره بالا میاره — ربات نمی‌خوابه، فقط اون فایل خاص
دوباره باید فرستاده بشه (یا سرور قوی‌تر بگیری).

**پیشنهاد:** شروع کن با رندر رایگان + `SMART_MODE=0` (سه حالت اول عالی کار می‌کنن).
اگه حالت جداسازی هوشمند رو زیاد می‌خوای، سرور Hetzner CPX11 (2GB، ~۴ یورو در ماه)
به‌مراتب به‌صرفه‌تر از رندر Standard (~۲۵ دلار) هست.

## 🎛️ استفاده از ربات

1. فایل صوتی بفرست (mp3 / wav / ogg / m4a / voice — تا ۲۰ مگابایت، محدودیت خود تلگرامه)
2. برای حالت «وکال + بیت» فایل دوم رو هم بفرست (اسم فایل‌ها رو بذار `vocal` و `beat` تا خودش تشخیص بده)
3. حالت رو انتخاب کن → از بین ۱۰ پریست انتخاب کن
4. فایل نهایی MP3 (کیفیت ۳۲۰kbps) رو تحویل بگیر ✅

**کامندها:** `/start` `/help` `/presets` `/on` `/off` `/test`

## ⚠️ درباره ملوداین و اتوتیون واقعی

ملوداین (Celemony) و اتوتیون (Antares) **هیچ API و نسخه سروری ندارن** — اتصال ربات بهشون
از نظر فنی غیرممکنه (فقط پلاگین دسکتاپ داخل DAW هستن). به جاش این پروژه از
**pyworld + الگوریتم اصلاح نت** استفاده می‌کنه:

- قدرت اصلاح ۳۰–۶۰٪ (بسته به پریست) → صدای رباتی نمی‌شه
- فقط نت‌های خارج از تون تا سقف مشخص (۴۵–۶۰ سنت) جابه‌جا می‌شن
- فرمانت‌ها (رنگ صدای طبیعی) دست نمی‌خوره
- فرکانس‌های بالای ۷.۵kHz (هوا و جزئیات تیس) از صدای اصلی حفظ می‌شه
- **تشخیص خودکار چندصدایی**: اگه ورودی کُر/چندنفره/ساز باشه (پرش نت بین فریم‌ها یا
  شباهت طیفی پایین)، اصلاح نت خودش رد می‌شه تا صدا خراب نشه — چون اصلاح نت فقط
  برای تک‌صدایی معنی داره (دقیقاً مثل ملوداین و اتوتیون واقعی)

اگه روزی این دو شرکت API عمومی بدن، کافیه ماژول `src/autotune.py` عوض بشه — بقیه پروژه سر جاش می‌مونه.

## 🖥️ اجرای محلی (اختیاری — برای تست)

```bash
pip install -r requirements.txt
cp .env.example .env   # توکن رو بذار
python bot.py
```
> روی ویندوز هم `install.bat` و `run.bat` هست. اگه حالت هوشمند می‌خوای: `pip install -r requirements-optional.txt` و `SMART_MODE=1`.

## 📁 ساختار پروژه

```
mixmaster-bot/
├── bot.py                 ← نقطه ورود ربات
├── config.py              ← تنظیمات (توکن، مسیرها)
├── requirements.txt       ← کتابخانه‌های سرور
├── requirements-optional.txt ← برای حالت هوشمند (Demucs + torch)
├── render.yaml            ← دیپلوی خودکار روی رندر
├── start.sh               ← اسکریپت شروع (وب + ربات)
├── .env.example
├── presets/
│   └── mastering_presets.yaml  ← ⭐ ۱۰ پریست — همه تنظیمات اینجاست، راحت ادیت کن
└── src/
    ├── handlers.py        ← منطق ربات تلگرام (منوها، حالت‌ها، پریست‌ها)
    ├── audio_engine.py    ← هسته صدا (EQ، کمپرسور، دی‌اسر، اشباع، LUFS، ...)
    ├── autotune.py        ← اصلاح نت نرم (جایگزین اتوتیون/ملوداین)
    ├── pipeline.py        ← اجرای حالت‌ها + جداسازی Demucs
    └── power.py           ← کلید روشن/خاموش (API رندر)
```
